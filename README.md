## 📌 Overview

The **Red-X Official Website** is a modern platform built for **Red-X, MIT Manipal**, designed to strengthen the club’s digital presence and community engagement.

The platform acts as a centralized hub for:

* 📅 Club events & activities
* 👥 Team & leadership showcase
* 🤝 Partner ecosystem & collaborations
* 📖 Club stories & experiences
* 🎨 Club branding and identity

Built with a **modern React stack**, the website focuses on **performance, responsiveness, and engaging UI/UX**.

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/your-username/redx-website.git
cd redx-website
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Runs locally at:

```bash
http://localhost:5173
```

## 🌍 Deployment

```bash

```

**Output Directory**

```bash

```

SPA routing fallback is configured through:

```bash

```
